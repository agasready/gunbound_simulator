gunbound_simulator

A web-based trajectory, power, and wind calculation simulator for the game Gunbound.

Live Demo

The application can be accessed and used directly via the following link:
gunbounesia.my.id/simulator

Key Features

Trajectory Calculation: Estimates the projectile landing point based on shooting angle and power bar.

Wind Adjustment: Factors in wind direction and speed to accurately predict projectile drift.

Mobile Support: Includes options for various mobiles, accounting for their unique shooting characteristics.

Web-Based Interface: Lightweight and runs directly in the browser without requiring any installation.

How to Use

Open gunbounesia.my.id/simulator in your browser.

Select the mobile you are using.

Input the wind direction and speed parameters matching your in-game conditions.

Adjust the target distance and firing angle to view the estimated power required.
